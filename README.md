# Aether Arcade

A warm, mobile-friendly browser start page with editable shortcuts, an embedded browsing view, and a searchable catalog of browser-playable games.

## Run locally

Open `index.html` in a modern browser or serve this folder with any static web server. No build step or runtime dependencies are required.

## Game links

Game cards link to the original publisher, developer, or archive. The address bar can show a destination in an iframe when the destination allows framing. Sites that send frame-blocking headers will not load there; use “Open in new tab” instead. This is a browser-side embed, not a server-side proxy, and does not bypass login, network, or site access controls. The project does not fetch, rewrite, or relay arbitrary third-party pages.

Shortcuts added by the visitor are stored in that browser's local storage. The search form sends text searches to Google and opens entered web addresses directly.
